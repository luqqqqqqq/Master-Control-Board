# PCB 制造资料

本目录包含生产所需的 BOM、贴片坐标和制造压缩包：

- `gerber-and-fabrication.zip`：Gerber/制板文件
- `bom.xlsx`：物料清单
- `pick-and-place.xlsx`：贴片坐标

## 下单前检查

1. 向板厂确认叠层、板厚、阻抗和铜厚。不同 PP 片材会改变最终厚度和阻抗，不能只按文件名下单。
2. 当前设计曾按 JLC 常见的 7628/3313 方案评估；具体选型请以板厂可提供的材料和阻抗计算为准。
3. 焊接后检查 RGB LED 方向：靠近按键的一侧为 R，左侧为 G，最右侧为 B。
4. 生产前重新核对封装、替代料和 BOM 版本，并在制造记录中保存板厂回传的叠层参数。
