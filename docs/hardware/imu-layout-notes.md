# BMI270 区域设计记录

BMI270 的零偏和温漂会受到 PCB 应变、外部振动和温度梯度影响。本文件记录当前版本的设计取舍，属于工程笔记，不能替代实测数据。

## 机械应力

- 在陀螺仪周围保留足够的开槽和净空，减少板弯和外壳装配力传递到器件。
- 外壳固定可以提高整体抗冲击能力，但螺丝和卡扣不能直接给 PCB 施加过大预紧力。
- PCB 加厚能提高刚性，同时会增加重量、成本和热阻，应通过振动与温漂测试决定是否采用。

## 热设计

- 可使用柔性导热垫或低应力固化导热材料帮助均温，但必须控制厚度和固化收缩。
- 导热材料不应挤压 BMI270，也不应遮挡需要保持开口的结构区域。
- 热路径应连接到连续铜区或外壳散热结构；单纯增加材料厚度不能替代温度测试。

## 验证建议

装配完成后，建议分别记录静置、升温、风扇扰动和振动条件下的零偏变化，并把测试结果与机械方案、导热材料批次一起归档。
